## 3. История циклов тестирования

### Цикл 0 — миграция в LangGraph и каркас (протокол доказательства)

Пять линий доказательства «всё в графе» (см. `docs/testing.md` §0): статический
анализ call-site, идентичность движка (CompiledStateGraph), инвентаризация
25/25 нод, сверка трасс с шагами Pregel (`stream_mode="updates"`), трассировщик
`BaseModule.run` с двумя намеренными пробами обхода — перехвачены стражем.

### Цикл 1 — эмбеддеры (детально: `docs/research/embedders.md`)

Три локальные модели через llama.cpp на GPU (8912 Qwen3-4B, 8913 Gemma-2, 8914
VL-2B), синтетика + реальный корпус + A/B «инструкция vs raw». Ключевые числа:

| Модель | Синтетика easy/hard | Реальный корпус (hit@1/hit@3/MRR) |
|---|---|---|
| Qwen3-4B + инструкция | 0.89 / 0.88 | 0.44 / 1.00 / 0.72 |
| Qwen3-4B raw | 0.78 / 0.88 | 0.44 / 0.56 / 0.58 |
| Gemma-2 (raw лучше) | 0.67 / 0.88 | 0.33 / 0.89 / 0.57 |
| VL-2B raw | 0.89 / 0.88 | 0.33 / 0.67 / 0.51 |

Выводы: Qwen3-4B с инструкцией на запросе — основной эмбеддер; документы
всегда сырые; VL принимает только сырой текст (префикс рушит hit@1 0.89→0.11).

### Цикл 2 — LM-провайдер и агентный слой (детально: `docs/research/lm-providers.md`)

- Модели OpenRouter: **GLM 5.3 Flash** — основная ($0.04/$0.08 за Мток,
  reasoning неотключаем), DeepSeek V4.1 Flash-1017 — запасная.
- Индексация корпуса через граф с настоящими провайдерами: 7 файлов,
  242 чанка, **2188 фактов** в базе знаний, 861.6 с, без ошибок.
- Демо маршрута `check`: нарушение (прямые кавычки → P 02-06, дефис →
  P 02-07) поймано вердиктом `violation` с дословной цитатой; нерелевантные
  пункты — `needs_review` с обоснованием.
- Анти-галлюцинация на узлах: цитаты, которых нет в источнике, бракуются.
- Расход: $0.068 из $1.

### Цикл 3 — реранкер и отчётная цепочка (детально: `docs/research/rerankers.md`)

- `Qwen3-Reranker-4B` Q8_0 через `llama-server --reranking` (порт 8915);
  для работы потребовался патч GGUF по официальному рецепту llama.cpp
  (`cls.output.weight` + `classifier.output_labels` + rerank-шаблон).
- A/B на СТО-корпусе: минимальный шаблон улучшил top-1/top-3
  (hit@1 0.22→0.44, hit@3 0.56→0.67, MRR 0.46→0.60); «официальная»
  веб-инструкция — вредит (та же мораль, что у эмбеддеров).
- Реализованы `rerank_fragments` (слияние трёх каналов + модельный реранк)
  и отчётная цепочка `aggregate_verdicts` → `compose_report` →
  `render_report` (Markdown-файл отчёта).
